      A free alt text checker that works on any page

      Alt text is the description a screen reader reads out in place of an image. It also shows up when an image fails to load, and search engines use it to understand what an image is about. Most sites have a few images with no alt at all, a lot with alt text like IMG_4032.jpg or image, and some links that are only an icon with nothing for a screen reader to say.

      This tool finds those. It checks <img>, inline <svg>, image buttons, image map areas, role="img" elements and CSS background images, then tells you what is missing and what's weak. It can't judge whether a description is good for your context; that part is on you, and the guide below helps.

      How to check missing alt text

      1. Add the bookmarklet. Drag the Check alt text button to your bookmarks bar.
      2. Open the page. Go to the page you want to check and click the bookmark.
      3. Review the report. Errors first, then warnings. Show on page scrolls to each image and outlines it.
      4. Export and fix. Download the CSV for your team or CMS, and rewrite weak alt text with the helper.

      How to write alt text

      Ask one question: if this image didn't load, what would the reader need to be told? The answer depends on why the image is there, not just what's in it. The same photo of a stage can be "Speaker Maya Chen opening the 2026 summit" on a news post and alt="" on a page where it's just a banner.

      • Be specific and brief. Lead with what matters.
      • Don't start with "image of" or "picture of". Do say "Screenshot", "Painting" or "Diagram" when the medium matters.
      • Don't stuff keywords. Write for people; search engines read it the same way.
      • Write it like a sentence. End with a period so screen readers pause.
      • If an image is a link or button, describe what it does, not what it looks like.
      • Decorative? Use alt="". Never leave the attribute out.

      Decorative vs informative vs functional images

      Informative images add information: describe that information. Decorative images add nothing a reader would miss: alt="". Functional images are links or buttons: describe the action or destination. When you're torn between informative and decorative, ask whether a blind reader would be missing out on something. If not, it's decorative. The W3C alt decision tree walks through edge cases.

      Text in images

      If an image contains text that matters, the alt needs those words. Better still, put the text in real HTML: it scales, translates, and works for everyone. WCAG 1.4.5 asks you to avoid images of text where real text can do the job (logos are the exception).

      WCAG 2.2 alt text requirements (1.1.1 Non-text Content)

      Success Criterion 1.1.1 Non-text Content, Level A. Every image, icon, chart or other non-text content shown to users needs a text alternative that does the same job as the original. The exceptions, in plain words:

      • Controls and inputs need a name that says what they do (an icon button needs a label).
      • Time-based media, tests and sensory experiences (like a piece of music or art) need at least a text label that identifies them.
      • CAPTCHAs need text saying what they are, plus an alternative that uses a different sense.
      • Decoration, formatting and invisible images must be hidden from assistive technology, for example with alt="".

      Read the official wording in WCAG 2.2 and the explanation in Understanding SC 1.1.1.

      WCAG doesn't set a character limit for alt text. The 125-character warning in this checker is a widely used rule of thumb.

      Image accessibility FAQ

      How do I check a page for missing alt text?

      Drag the Check alt text bookmarklet to your bookmarks bar, open the page and click it. It lists every image, flags missing or weak alt text and lets you jump to each image. You can also paste a page's HTML into the Paste HTML tab.

      Is empty alt text (alt="") an error?

      No. alt="" tells screen readers to skip the image, which is correct for decoration. It is a problem when the image carries meaning, or when it is the only thing inside a link or button, because then the link has no name.

      How long should alt text be?

      As short as it can be while still doing the job. WCAG sets no limit. Around 125 characters is a common rule of thumb; if you need more, put the detail in a caption or nearby text.

      Should alt text start with "image of" or "photo of"?

      Usually not. Screen readers already announce it as an image. Mention the medium only when it matters, like a painting, a screenshot or a diagram.

      What alt text should a logo have?

      The organization's name. If the logo links to the home page, use the name plus where it goes, like "FirstShow home". If the name is already written right next to it, use alt="".

      Do background images need alt text?

      CSS background images cannot have alt text, so screen readers skip them. That is fine for decoration. If a background carries meaning, put that meaning in real text on the page or use an <img> element with alt.

      Why can't this tool check any URL I type in?

      Browsers stop one website from reading another website's pages unless that site allows it (CORS). Most sites don't. The bookmarklet gets around this because it runs on the page you are already viewing.

      Does this tool send my HTML or my page anywhere?

      No. The audit runs in your browser. There is no server, no account and no analytics. Thumbnails in the report load straight from where the images are hosted, and you can turn them off.
